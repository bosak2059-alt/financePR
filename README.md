💰 Finance Tracker — Личный финансовый помощник
Веб-приложение для учета личных доходов и расходов, построенное на Python (Flask) с использованием базы данных MySQL. Приложение позволяет вести бюджет, анализировать траты через наглядные графики и формировать отчеты.
🚀 Технологии:
    Backend: Python, Flask, SQLAlchemy
    Database: MySQL (через PyMySQL)
    Frontend: HTML5, CSS3 (Bootstrap 5), JavaScript (Chart.js)
    Auth: Flask-Login, Werkzeug (хеширование паролей)

🛠️ Установка и запуск
Предварительные требования:
1) Установленный Python 3.8+.
2) Установленный и запущенный сервер MySQL (например, через XAMPP, MAMP или standalone установку).
3) Созданная база данных с именем finance_tracker (или измените имя в .env).

Пошаговая инструкция: 
1) Клонирование репозитория и установка зависимостей:
    git clone <ссылка_на_репозиторий>
    cd finance-tracker
    pip install -r requirements.txt

2) Настройка конфигурации:
Создайте файл .env в корневой папке проекта (или в папке base/, согласно config.py) и укажите параметры подключения к БД:
    SECRET_KEY=ваш_секретный_ключ
    MYSQL_USER=root
    MYSQL_PASSWORD=ваш_пароль_от_mysql
    MYSQL_HOST=127.0.0.1
    MYSQL_PORT=3306
    MYSQL_DB=finance_tracker

Примечание: Если вы используете MySQL Workbench, убедитесь, что сервер запущен и база данных finance_tracker создана. Таблицы создадутся автоматически при первом запуске приложения.

3) Запуск приложения: python app.py
Приложение будет доступно по адресу: http://127.0.0.1:5000

📖 Руководство пользователя
1) Регистрация и Вход
    При первом посещении сайта вам необходимо зарегистрироваться:
    1. Перейдите на страницу Регистрация.
    2. Введите имя пользователя, email и пароль.
    3. После успешной регистрации система автоматически создаст для вас набор базовых категорий (Еда, Транспорт, Зарплата и т.д.).
    4. Войдите в систему, используя свои учетные данные.
2) Дашборд (Главная страница)
    Главная страница предоставляет сводную информацию о вашем финансовом состоянии:
    1. Карточки статистики: Отображают общий баланс, доходы и расходы за текущий месяц.
    2. Графики:
        2.1 Круговая диаграмма: Распределение расходов по категориям за текущий месяц.
        2.2 Линейный график: Динамика доходов и расходов за последние 6 месяцев.
    3. Последние операции: Список из 10 последних транзакций. Здесь же доступны быстрые действия:
        ✏️ Редактировать: Изменить сумму, дату или описание.
        🗑️ Удалить: Удалить запись (требуется подтверждение).
    4. Кнопка «Все транзакции» перенаправляет на страницу подробных отчетов.
3) Добавление транзакции
    Для внесения новой записи нажмите кнопку «Добавить» в меню навигации.
    Алгоритм действий:
    1. Тип операции: Выберите «Расход» или «Доход».
        Важно: Список категорий автоматически обновляется в зависимости от выбранного типа.
    2. Категория: Выберите соответствующую категорию из выпадающего списка.
    3. Сумма: Введите числовое значение (поддерживаются копейки).
    4. Дата: Выберите дату операции (по умолчанию подставляется текущая дата).
    5. Описание: (Необязательно) Добавьте комментарий к операции.
    6. Нажмите «Сохранить».

4) Отчеты
    Страница «Отчеты» содержит полную историю всех ваших операций.
    Возможности:
    1. Фильтрация: Вы можете отфильтровать транзакции по:
        Диапазону дат (с ... по ...).
        Конкретной категории.
    2. Пагинация: Удобный просмотр больших списков данных (по 20 записей на странице).
    3. Итоговая сумма: Отображается общая сумма выбранных транзакций.

⚙️ Особенности реализации
1. Безопасность: Пароли хранятся в хешированном виде. Все формы защищены от CSRF-атак. Доступ к данным строго ограничен: пользователь видит только свои транзакции.

2. Динамические формы: Категории в форме добавления транзакции фильтруются на стороне сервера перед отображением, что исключает выбор некорректных данных.

3. Аналитика: Графики строятся на клиентской стороне с помощью библиотеки Chart.js, получая агрегированные данные от API Flask.
