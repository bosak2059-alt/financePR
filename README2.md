## 🔧 Детальное описание компонентов

### 1. Config.py — Настройки окружения и БД

| Параметр                        | Назначение                                          |
|---------------------------------|-----------------------------------------------------|
| `SECRET_KEY`                    | Для подписи сессий и защиты CSRF                   |
| `MYSQL_USER`, `MYSQL_PASSWORD`  | Параметры подключения к MySQL                      |
| `SQLALCHEMY_DATABASE_URI`       | Строка подключения в формате `mysql+pymysql://...` |
| `SQLALCHEMY_TRACK_MODIFICATIONS`| Отключение уведомлений SQLAlchemy (экономия памяти)|
| `UPLOAD_FOLDER`                 | Путь для загрузки файлов                           |

### 2. Models.py — ORM-модели базы данных

#### Модель User (Пользователь)
| Поле            | Тип данных     | Описание                     |
|-----------------|----------------|------------------------------|
| `id`            | Integer        | Первичный ключ               |
| `username`      | String(80)     | Уникальное имя пользователя  |
| `email`         | String(120)    | Уникальный email             |
| `password_hash` | String(255)    | Хешированный пароль          |
| `created_at`    | DateTime       | Дата создания аккаунта       |

#### Модель Category (Категория)
| Поле      | Тип данных     | Описание                              |
|-----------|----------------|---------------------------------------|
| `id`      | Integer        | Первичный ключ                        |
| `user_id` | Integer        | Внешний ключ на пользователя          |
| `name`    | String(50)     | Название категории                    |
| `type`    | String(10)     | Тип: `'income'` или `'expense'`       |
| `icon`    | String(50)     | Иконка Bootstrap (по умолчанию)       |

#### Модель Transaction (Транзакция)
| Поле          | Тип данных        | Описание                     |
|---------------|-------------------|------------------------------|
| `id`          | Integer           | Первичный ключ               |
| `user_id`     | Integer           | Внешний ключ на пользователя |
| `category_id` | Integer           | Внешний ключ на категорию    |
| `amount`      | Numeric(10, 2)    | Сумма операции               |
| `date`        | DateTime          | Дата операции                |
| `description` | Text              | Описание (опционально)       |

#### Модель Budget (Бюджет)
| Поле           | Тип данных     | Описание                              |
|----------------|----------------|---------------------------------------|
| `id`           | Integer        | Первичный ключ                        |
| `user_id`      | Integer        | Внешний ключ на пользователя          |
| `category_id`  | Integer        | Внешний ключ на категорию             |
| `limit_amount` | Numeric(10, 2) | Лимит суммы                           |
| `period`       | String(20)     | Период: `'monthly'` или `'weekly'`   |

### 3. Forms.py — Валидация и работа с формами

| Форма               | Поля                                  | Валидаторы                          |
|---------------------|---------------------------------------|-------------------------------------|
| `LoginForm`         | username, password, submit            | DataRequired, Length                |
| `RegistrationForm`  | username, email, password, confirm    | DataRequired, Email, EqualTo        |
| `TransactionForm`   | type, category, amount, date, desc    | DataRequired, NumberRange, Length   |
| `BudgetForm`        | category, limit_amount, period, submit| DataRequired, NumberRange           |

### 4. App.py — Ключевые маршруты

| Маршрут                        | Метод    | Описание                          |
|--------------------------------|----------|-----------------------------------|
| `/`                            | GET      | Дашборд с аналитикой              |
| `/templates/login`             | GET/POST | Вход в систему                    |
| `/templates/register`          | GET/POST | Регистрация                       |
| `/templates/add_transaction`   | GET/POST | Добавление транзакции             |
| `/templates/reports`           | GET      | Отчеты с фильтрацией              |
| `/transaction/edit/<int:id>`   | GET/POST | Редактирование транзакции         |
| `/transaction/delete/<int:id>` | GET      | Удаление транзакции               |
| `/api/category_stats`          | GET      | API для графика категорий         |
| `/api/trend_stats`             | GET      | API для графика трендов           |

## 🔄 Сценарий использования

| Шаг | Действие пользователя              | Реакция системы                                  |
|-----|------------------------------------|--------------------------------------------------|
| 1   | Запуск `python app/app.py`         | Чтение `.env` → инициализация БД → сервер :5000 |
| 2   | Регистрация                        | Валидация → создание User → генерация категорий |
| 3   | Вход в систему                     | Проверка пароля → создание сессии                |
| 4   | Добавление транзакции              | Выбор типа → загрузка категорий → сохранение в БД|
| 5   | Просмотр аналитики                 | SQL-запросы с JOIN/GROUP BY → отрисовка графиков|
| 6   | Безопасность                       | Фильтр `user_id == current_user.id` на всех запросах |

## 📥 Установка и запуск

### Предварительные требования
| Требование     | Версия / Описание        |
|----------------|--------------------------|
| Python         | 3.8+                     |
| MySQL Server   | 5.7+ или 8.0+            |
| pip            | Актуальная версия        |

### Пошаговая инструкция

| Шаг | Команда / Действие                              | Описание                              |
|-----|-------------------------------------------------|---------------------------------------|
| 1   | `git clone <repository_url>`<br>`cd finance`    | Клонирование репозитория              |
| 2   | `pip install -r base/requirements.txt`          | Установка зависимостей Python         |
| 3   | Создать `base/.env` с параметрами БД            | Настройка переменных окружения        |
| 4   | `CREATE DATABASE finance_tracker;`              | Создание базы данных в MySQL          |
| 5   | `cd app`<br>`python app.py`                     | Запуск Flask-сервера                  |
| 6   | Открыть `http://127.0.0.1:5000` в браузере      | Доступ к приложению                   |

## 🎯 Основные возможности

### Управление транзакциями
| Функция              | Описание                              |
|----------------------|---------------------------------------|
| Добавление           | Внесение доходов и расходов           |
| Редактирование       | Изменение суммы, даты, описания       |
| Удаление             | Удаление записей с подтверждением     |
| Категоризация        | Привязка к пользовательским категориям|

### Аналитика и отчеты
| Функция              | Описание                              |
|----------------------|---------------------------------------|
| Общий баланс         | Расчет: доходы − расходы              |
| Статистика за месяц  | Агрегация по текущему периоду         |
| Круговая диаграмма   | Распределение расходов по категориям  |

| Механизм             | Описание                              |
|----------------------|---------------------------------------|
| Хеширование паролей  | Werkzeug + generate_password_hash     |

| Изоляция данных      | Фильтр по `user_id` в каждом запросе  |
| Сессии               | Flask-Login + secure cookies          |

## 📚 Структура базы данных (SQL)

### Таблица `users`
| Поле            | Тип данных     | Ограничения              |
|-----------------|----------------|--------------------------|
| `id`            | INT            | PRIMARY KEY              |
| `username`      | VARCHAR(80)    | UNIQUE, NOT NULL         |
| `email`         | VARCHAR(120)   | UNIQUE, NOT NULL         |
| `password_hash` | VARCHAR(255)   | NOT NULL                 |
| `created_at`    | DATETIME       | DEFAULT NOW()            |

### Таблица `categories`
| Поле      | Тип данных     | Ограничения              |
|-----------|----------------|--------------------------|
| `id`      | INT            | PRIMARY KEY              |
| `user_id` | INT            | FOREIGN KEY → users.id   |
| `name`    | VARCHAR(50)    | NOT NULL                 |
| `type`    | VARCHAR(10)    | 'income' / 'expense'     |
| `icon`    | VARCHAR(50)    | DEFAULT 'bi-circle'      |

### Таблица `transactions`
| Поле          | Тип данных        | Ограничения              |
|---------------|-------------------|--------------------------|
| `id`          | INT               | PRIMARY KEY              |
| `user_id`     | INT               | FOREIGN KEY → users.id   |
| `category_id` | INT               | FOREIGN KEY → categories.id |
| `amount`      | DECIMAL(10,2)     | NOT NULL                 |
| `date`        | DATETIME          | INDEX                    |
| `description` | TEXT              | NULLABLE                 |

### Таблица `budgets`
| Поле           | Тип данных     | Ограничения              |
|----------------|----------------|--------------------------|
| `id`           | INT            | PRIMARY KEY              |
| `user_id`      | INT            | FOREIGN KEY → users.id   |
| `category_id`  | INT            | FOREIGN KEY → categories.id |
| `limit_amount` | DECIMAL(10,2)  | NOT NULL                 |
| `period`       | VARCHAR(20)    | 'monthly' / 'weekly'     |
